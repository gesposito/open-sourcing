# Adopted references

These are the external sources our [guidelines](../guidelines/README.md) are built from.
A reference is *adopted* when we map each of its recommendations to a rule ID, or record
why we don't follow it.

| Tag | Reference | Adopted | Notes |
| --- | --- | --- | --- |
| [Astral] | [Open source security at Astral](https://astral.sh/blog/open-source-security-at-astral) | 2026-11-01 | [astral.md](astral.md) |
| [StarSling] | [GitHub Actions best practices](https://starsling.dev/best-practices/github-actions) | 2026-11-01 | [starsling-github-actions.md](starsling-github-actions.md) |

## Template for a new reference

```markdown
# <Title>

- **URL:**
- **Author / publisher:**
- **Published / last updated:**
- **Adopted on:**

## Summary
Two or three sentences.

## Mapping
| Recommendation | Rule | Notes |
| --- | --- | --- |

## Deviations
What we don't follow, and why.

## Revisit
When to re-read it (for example, "when GitHub ships enforceable passkey-only 2FA").
```
